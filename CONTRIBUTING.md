# Contributing to Gemini Computer Task Execution Skill

Contributions to expand macOS AppleScript (`osascript`) and shell automation workflows are welcome!

## Guidelines

1. **Zero-Screenshot First:** Keep all workflows text- and IPC-based (`open -a`, `osascript`, System Events).
2. **Safety First:** Never add patterns that automate password fields, keychain prompts, or system authorization dialogs.
3. **Verify Locally:** Test every AppleScript snippet in macOS Terminal before opening a pull request.
